# Ticket Companion

## Vision

Ticket Companion is a Progressive Web App that allows friends to play Ticket to Ride remotely while using their own physical game boards.

The app synchronizes all hidden game information:

- Train cards
- Destination tickets
- Turn order
- Shared decks
- Discard piles

The physical board remains the source of truth for:

- Trains
- Claimed routes
- Board state

The app exists only to synchronize hidden information between players.
